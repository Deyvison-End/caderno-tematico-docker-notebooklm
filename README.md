# Fontes utilizadas

As fontes abaixo foram selecionadas para apoiar o estudo sobre Docker no NotebookLM. Foram escolhidos materiais que abordam desde os conceitos fundamentais de containers até Dockerfile, Docker Compose, redes, volumes, imagens e Docker Registry.

https://www.dio.me/articles/como-realizar-o-upload-de-imagens-para-o-docker-hub-e-criar-um-docker-registry-privado

**Tema:** Docker Hub, upload de imagens e Docker Registry privado.

## Critério de seleção

As fontes foram selecionadas buscando contemplar diferentes aspectos do Docker, desde seus conceitos fundamentais até recursos utilizados na prática, como Dockerfile, Compose, Networks, Volumes, Docker Hub e Registry.

A utilização de diferentes fontes também permitiu comparar explicações sobre os mesmos conceitos e utilizar o NotebookLM para organizar e consolidar o conteúdo estudado.
